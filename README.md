# BCL Dashboard

Basketball Champions League komandų suvestinė.

## Gyvena

https://andriuspanama.github.io/bcl-dashboard/

## Kaip atnaujinti duomenis

Redaguok `data/teams.json` ir įkelk pakeitimus. Puslapis atsinaujins automatiškai per ~1 min.

## Struktūra

- `index.html` — visa aplikacija (HTML + CSS + JS)
- `data/teams.json` — komandų duomenys
- `.github/workflows/static.yml` — automatinis deploy į GitHub Pages
